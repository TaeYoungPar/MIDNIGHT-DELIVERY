## 최신: 괴물 가시성·출발선·탑승 중 상호작용 제한

- 사용자 실제 보고로 괴물 등장 자체는 확인됐으나 너무 가까워 잘 안 보였습니다. 새 등장 연출은 아직 재검증 전입니다.

- LobbyBoundary: 대기 구역 네 면의 출발선/차단벽과 안내문. 대기·준비·결과에서 닫히고 PLAYING에서 개방. 비참가자는 서버 위치 검사로 복귀시키며 차량은 먼저 복구합니다. 준비 중 목적지 정보는 전송하지 않습니다.

- 77개 번호 있는 검사 및 컨트롤러/통합/월드 검사, 45개 소스 빌드 PASS. 실제 유령 시야/차단벽/복제/멀티플레이는 미검증.
- 추가 사용자 보고: 퀘스트 완료 후 다음 판 진행 안 됨. 원인 미확정. 결과15+대기20+준비10초 모델 및 20회 연속 전환은 대역에서 통과합니다. 판/단계 카운트다운과 서버 전환 로그를 추가했으며 실제 화면 상태/Output 확인이 필요합니다.

## 최신 수정: 안내판 통행·노크음·남은 차량 떨림

- 사용자 보고: 파란 지붕집 안내판이 길을 막고, 스쿠터에 약한 떨림이 남음. 해결 완료로 간주하지 않고 새 수정의 실플레이 재검증을 기다립니다.
- `Primitives.sign`의 간판과 `NavigationSigns`의 전체 길안내 부품에 CanCollide/CanTouch/CanQuery=false. 벽·집·우편함 본체의 충돌은 유지합니다.
- 서버가 유효한 노크를 세었을 때만 근처 플레이어에게 Knock cue 발행. 기존 Feedback 메시지에 선택적 cue 인자를 추가하고 클라이언트에서 허용된 Knock만 재생합니다. 소리 꺼짐을 따릅니다.
- 노크는 내장 착지 충격음의 음높이를 바꾼 짧은 타격음입니다. 실제 나무 문 녹음이라고 주장하지 않습니다. 음원 추가 업로드는 없습니다.
- 배달 완료/실패 후 알림에 다음 주문 제목을 연결해 파란집 이후 다음 목적지로 이어갑니다.
- 서버 차량의 Model:PivotTo를 기준 좌석 CFrame 갱신으로 바꾸어 단일 용접 어셈블리를 한 번 이동. 조향 입력을 지수 완충하고 하차/재탑승 시 잔여 조향을 초기화합니다. 서버 충돌/속도/권한 검사는 유지합니다.
- 자동 회귀 76개 및 추가 오디오/통합/월드 검사, 44개 소스 컴파일·빌드 검사 PASS. 실제 Studio의 통행/노크 청취/잔여 떨림은 미검증입니다.

## 최신 수정: 심한 떨림·발소리 같은 차량음

- 사용자 보고는 실패 증거로 유지합니다. 이번 수정의 실제 Studio/모바일/멀티플레이 결과는 **미검증**입니다.
- `VehicleService`: 불규칙한 30Hz Heartbeat 게이트를 제거하고 물리 계산 전 PreSimulation에서 이동. 지면 광선에서 모든 차량/플레이어를 제외하고 도로·차선 높이 차이를 지수 완충. 급한 단차로 올라타기 차단. 탑승자와 자기 차체의 충돌/자동 회전을 억제하고 자연 하차·명시적 하차·종료 시 복원.
- `VehicleFactory`: 좌석만 anchored, 나머지는 massless 용접 구조로 통합. Body 외 장식/바퀴/상자/좌석의 물리 충돌 제거.
- `VehicleController`: 차량 프레임을 보간한 뒤 카메라 위치와 주시점을 함께 계산. 벽을 벗어날 때 카메라 암을 완충하고 큰 위치 복구 때 이전 보간 상태 폐기.
- `AudioController`/`AudioCatalog`: 발소리 Motor 제거, 공개 차량 예제에서 실제 확인한 엔진 루프 참조. 공회전·속도별 음높이/음량 완충, 탑승 중 Running 소리 억제·하차 복원. 외부 오디오 에셋의 경험별 재생 권한/청취는 Studio 확인 필요. 출처는 `AUDIO_SOURCES.md`.
- 자동 검사: 번호 있는 로직/대역 **76개 PASS**, 카메라/오디오/입력/통합/월드 추가 검사 PASS, 44개 소스 컴파일·패키징 검사 PASS. 아래 기록은 이전 단계입니다.

## 최신 수정: 주행 시점·소유 표시·하차

- `VehicleController.luau`: anchored 차량용 후방 추적 카메라, 복제 위치 보간, 벽 앞 카메라 거리 축소, 하차/사망/종료 시 기본 카메라 복귀. 내 스쿠터의 민트빛 Highlight/상단 표시, 다른 차량 프롬프트 숨김, 소유권 변경 반영.
- `InputController.luau`: 기본 차량 입력보다 높은 우선순위의 X/Space 하차, 112×56 하차 버튼, 주행 중 조작 안내, GUI 표시 순서 조정. 도보 Space와 채팅 입력은 가로채지 않음.
- `VehicleService.luau`: Occupant 갱신 순서에만 의존하지 않고 소유 캐릭터의 SeatWeld를 먼저 제거. 주변 지면/경사/벽/빈 공간 검사 후 안전 하차, 공간 없으면 본부 복귀, 1초 재탑승 제한, 반복 하차 이동 방지. 차량 복구의 지연된 캐릭터 재배치 제거.
- `VehicleFactory.luau`: 본인 차량의 배달 상자가 탑승 안내를 가리지 않도록 프롬프트 시야 검사 해제. 서버 소유권/거리/상태 검사는 유지.
- 자동 검사: 번호 있는 로직/대역 **73개 PASS**, 새 클라이언트 카메라/소유 표시/입력 대역 검사 PASS, 기존 전체 회귀 검사/빌드 **44개 소스** PASS. 실제 렌더링·SeatWeld 물리·모바일 터치는 미검증.
