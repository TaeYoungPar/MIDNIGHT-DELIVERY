# 알려진 제한 · 2026-10-29

- Linux 클라우드에는 Roblox Studio가 없습니다. P2의 실제 렌더링/물리/복제/터치는 미검증이며 출시 가능한 빌드가 아닙니다.
- **괴물 추격 AI는 미구현**입니다. P2 고객 규칙 위반 시 위험 자막/재시도 잠금만 적용합니다. 실제 추격/기절/구조는 P3에서 함께 구현하여 기절 뒤 영구 잠김을 방지합니다. 이는 원본 기획 대비 단계별 구현 차이이며, 추격이 된다고 보고하지 않습니다.
- 고객 순서는 무작위 추첨 대신 라운드별 순환입니다. 첫 판 학습 순서와 재현 가능한 QA를 확보하기 위함이며 가짜 집 정답도 순환합니다. 향후 seed 기반 셔플로 확장할 수 있습니다.
- Coins/XP는 세션 전용이며 퇴장/서버 종료 시 초기화됩니다. 저장/레벨/상점/꾸미기는 P5.
- 차량/스프린트/커스텀 캐릭터/음향/접근성 설정/맵 외곽 경계/낙하 복구는 미구현입니다. 기본 Roblox 캐릭터/조작 사용.
- 지면은 650 studs이며 도보 가능한 동선을 우선했습니다. 차량 도입 후 스쿠터 25~60초 이동 동선과 목적지별 두 개 도주 경로를 실측해야 합니다.
- 방향 검사는 서버가 본 캐릭터의 방향입니다. 카메라만 돌려도 자동 위반하지 않습니다. 기본 이동 방식에 따라 캐릭터가 문을 향하도록 조작해야 합니다.
- 유령은 팀 공유 노크와 마지막 노크 수행자 한 명의 4초 유지로 검사합니다. 그 사람이 이탈/사망/범위 이탈하면 재시도/실패 경로로 전환합니다.
- 서버 이동 검사는 급격한 위치 변화에 3초 배달 지연을 주는 초기 휴리스틱입니다. 느린 위치 위조/장시간 텔레포트 방어가 완성된 것은 아닙니다. P4에서 이동 모드/차량 권위와 함께 강화하고 지연 오탐도 검사해야 합니다.
- ProximityPrompt HoldDuration 자체를 보안 근거로 신뢰하지 않습니다. 거인 진정은 서버의 HoldBegan 시각·주문 키·생존·근접 유지·Triggered 시각을 추가 검사합니다. 유령 노크 홀드는 UX용이며 서버 쿨다운을 별도로 적용합니다.
- 경험 정원 4명은 Roblox 경험 설정에서 직접 지정합니다. 코드가 플랫폼 정원을 바꾸지 않습니다.
- 기존 Place의 기본 Baseplate/Spawn/사용자 조명은 삭제하지 않습니다. 빌드 파일 열기 또는 빈 Place 사용 권장.
- 다운로드 ZIP은 GitHub 저장소의 `downloads/MidnightDelivery-Studio.zip`입니다. 비공개라면 저장소 접근 가능한 계정 로그인이 필요합니다. ZIP 배포는 Roblox 게임 게시나 Studio 실행 검증을 의미하지 않습니다.
