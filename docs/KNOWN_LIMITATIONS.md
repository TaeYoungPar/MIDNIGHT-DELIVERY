# 알려진 제한 · P3 / 2026-10-29

## 아직 검증하지 못한 것

Linux 클라우드에는 Roblox Studio가 없습니다. 실제 NPC Humanoid 보행/물리/Pathfinding/네트워크 소유권, 초기 캐릭터·카메라 방향, 모바일 구조 버튼, 2~4인 복제와 성능은 Studio 미검증입니다. 코드와 headless 데이터 모델/대역 테스트가 통과했어도 P3/출시 QA 통과로 선언하지 않습니다.

## P3 구현 선택과 제한

- NPC는 용접한 오리지널 임시 모델이며 걷는 애니메이션/음원은 아직 없습니다. 물리/콜라이더/크기 튜닝은 Studio 결과로 조정해야 합니다.
- 한 번에 한 괴물만 활성화합니다. 주문이 끝나면 추격도 정리합니다. 즉시 주문 실패가 되는 유령 마지막 위반/가짜 집 두 번째 오답에서는 다음 주문 진행을 우선하여 추격을 새로 시작하지 않습니다.
- 거인 온도 초과는 별도 행동 유발자가 없는 시간 기반 사건이라 가장 가까운 유효 참가자를 추격합니다. 유령은 마지막 노크 수행자, 집 괴물은 오답 수행자를 추격합니다.
- 기절은 사망/ragdoll 대신 캐릭터 루트 고정과 이동 제한입니다. 팀 구조는 그 자리, 12초 자동 복귀는 가까운 도로 체크포인트입니다. 유효 구조자는 현재 라운드 참가자이며 자기 자신/기절한 사람/대기자는 제외합니다.
- 구조 3초 검사는 네트워크 도착 차이에 0.15초 오차를 허용합니다. 거리 이탈/시야 차단/사망/캐릭터 교체/홀드 취소를 재검사합니다.
- 서버 위치 검사는 급격한 이동에 3초 배달 지연을 주는 초기 휴리스틱입니다. 느린 위치 위조/장시간 텔레포트 방어가 완성된 것은 아닙니다. P4 이동 모드/차량 권위와 함께 강화하고 지연 오탐도 검사해야 합니다. 자동 도로 복귀 직후 정상 서버 이동에도 잠시 배달 지연이 적용될 수 있습니다.
- 화면별 HUD/긴 팀원 이름/모바일 프롬프트 겹침, 카메라 한 번 정렬 후 기본 컨트롤 유지 여부는 실기기 QA가 필요합니다.

## 남은 기능/설계 조정

- 스쿠터/스프린트/외곽 경계·낙하 복구(P4), 영구 저장/레벨/상점/꾸미기(P5), 사운드/접근성/30FPS 실기기/출시 QA(P6)는 미구현입니다.
- Coins/XP는 세션 전용으로 퇴장/서버 종료 시 초기화됩니다. 유료 상품/외부 에셋/Roblox 비밀 키는 사용하지 않습니다.
- 주문 순서와 가짜 집 정답은 라운드별 순환입니다. 학습 순서와 QA 재현을 우선한 선택이며 향후 seed 기반 셔플로 확장 가능합니다.
- 지면 650 studs, 현재 도보 동선 우선입니다. 차량 도입 후 스쿠터 25~60초 이동과 두 개 도주 경로를 실측해야 합니다.
- 경험 정원 4명은 Roblox 경험 설정에서 직접 지정합니다. 기존 Place의 기본 Spawn/Baseplate/조명은 삭제하지 않으므로 배포 파일 열기 또는 빈 Place 사용을 권장합니다.
- 직접 배포 파일은 `downloads/MidnightDelivery.rbxlx`입니다. ZIP 배포를 중단했습니다. 비공개 저장소는 접근 가능한 GitHub 로그인이 필요하며, 파일 배포는 Roblox 게임 게시가 아닙니다.
