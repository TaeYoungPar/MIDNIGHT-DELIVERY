# 알려진 제한 · P5 / 2026-10-29

## 실제 기기 미검증

Linux 클라우드에는 Roblox Studio가 없습니다. 실제 스쿠터 탑승/SeatWeld 전달/주행/충돌, NPC 물리/경로, 초기 카메라, 모바일 버튼/복제/지연/성능, 내장 음원 재생·청취는 NOT TESTED입니다. 모의 검사 PASS를 P5 통과나 출시 준비 완료로 해석하지 않습니다.

## 차량 설계 조정

- 스쿠터는 전복을 방지하는 **서버 아케이드 방식**입니다. VehicleSeat와 모델은 anchored이며, 서버가 30Hz로 위치/회전을 계산하고 overlap/Blockcast/ground ray를 검사합니다. 자유로운 물리 서스펜션/전복/바퀴 회전 애니메이션이 있는 시뮬레이션이 아닙니다. 기존 설계의 간단한 차량 옵션을 선택하여 소유권과 속도 권위를 서버에 유지했습니다.
- 실제 좌석 용접이 캐릭터를 따라 움직이게 하는지 Studio에서 반드시 확인해야 합니다. 단순히 모델이 만들어졌다는 검사로 주행 성공을 보고하지 않습니다.
- 급경사/단차/물/특이 Terrain 주행은 미검증입니다. 현재 자동 생성 평지/도로를 대상으로 합니다. 장애물에 끼면 소유자 복구 버튼으로 주차 위치로 돌아갑니다.
- 차량 복구는 유저 근처가 아니라 자기 본부 주차 칸으로 돌아갑니다. 15초 쿨다운이며 탑승 중이면 함께 안전 하차합니다. 차량 입력이 0.4초 이상 끊기면 제동합니다.
- 서버의 좌석 거리 검사는 지연/SeatWeld 재현 오차로 하차를 유발할 수 있어 높은 latency QA가 필요합니다.
- 주행 최대 속도는 Config.Vehicle.MaxSpeed에서 조정합니다. 4인 움직임의 복제/캐스트 비용과 실제 모바일 30FPS는 미측정입니다.

## 사운드/UI

- 별도 업로드 없이 들을 수 있도록 공식 Core-Scripts에 사용된 `rbxasset://sounds/` 기본 음색을 재사용했습니다. 전용 오리지널 배달 징글/괴물 보이스/스쿠터 엔진 녹음은 아닙니다. 초기 사운드 재생 파이프라인이며 최종 음향 폴리시가 필요합니다.
- 내장 파일 제공 여부는 클라이언트 버전에 따라 Studio에서 확인해야 합니다. Preload 실패를 경고하고 자막/HUD로 계속 알립니다. 이 환경에서는 음원이 실제로 들리는지 검증하지 못했습니다.
- 음소거는 로컬 SoundGroup에 연결하며 기본 캐릭터 소리도 로컬에서 그룹에 포함합니다. 다른 참가자의 설정에는 영향을 주지 않습니다. 설정/재화는 현재 세션 전용입니다.
- 48px 모바일 방향 버튼, 달리기/하차/복구/소리 버튼을 추가했지만, 기기별 조이스틱/점프/프롬프트/주문 카드 겹침은 실기기 QA가 필요합니다.

## 기존 제한

- 영구 저장/레벨/상점/꾸미기 코드가 추가되었으나 실제 저장/복원은 Roblox에서 미검증입니다. 사운드·접근성·출시 폴리시는 P6입니다.
- 추격 NPC는 외부 리그 없는 용접 모델로 걷는 애니메이션이 없습니다. 주문 종료 시 NPC 정리. 즉시 주문 실패가 되는 최종 규칙 위반에는 새 추격을 시작하지 않고 다음 주문을 우선합니다.
- 기절은 ragdoll이 아니라 이동 제한입니다. 팀 구조는 그 자리, 자동 복귀는 도로 체크포인트, 보호 4초. 구조 홀드는 네트워크 차이 0.15초를 허용하고 거리/시야/상태/취소를 재검사합니다.
- 이동 보안은 초기 휴리스틱입니다. 차량 자체는 서버가 이동하지만 일반 캐릭터의 느린 위치 위조/텔레포트 방어까지 완성된 것은 아닙니다. P6 보안/latency QA가 남았습니다.
- 주문 순서/정답은 QA 재현을 위한 라운드별 순환입니다. 차량 추가 후 동선 25~60초와 두 개 도주 경로를 실측해야 합니다.
- 경험 정원 4명은 Roblox 경험 설정에서 직접 지정합니다. 기존 Place의 별도 Spawn/Baseplate/조명은 삭제하지 않으므로 직접 빌드 파일 또는 빈 Place 사용 권장.
- 직접 배포는 `downloads/MidnightDelivery.rbxlx`. 비공개 저장소는 GitHub 로그인 필요. 파일 업로드는 Roblox 게임 게시가 아닙니다.


## P5 저장과 상점

- 미게시 rbxlx 파일 또는 API 접근 실패/다른 서버 잠금/손상 데이터에서는 세션 전용입니다. 이 상태에서는 기존 영구 데이터에 쓰지 않으며 상점을 잠급니다. 저장 테스트는 별도의 비공개 경험에 게시하고 Studio API Services를 허용해야 합니다.
- Studio와 앱은 서로 다른 DataStore 이름을 사용합니다. Studio 재화가 앱에 안 나타나는 것은 정상입니다. 실제 앱에서도 별도로 재접속을 시험해야 합니다.
- 임대 180초/갱신 60~74초와 만료 전 30초 보호를 사용합니다. 저장 권한이 사라지면 해당 접속의 이후 진행은 세션 전용이고 상점은 잠깁니다. 이미 진행한 마지막 미저장 구간은 서버 강제 종료/긴 장애에서 유실될 수 있으며 이를 완전히 방지했다고 주장하지 않습니다.
- 저장 오류 시 구매를 중단하고 이후 자동 저장을 재시도합니다. 저장 콜백 안에서는 구매/보상/클라이언트 호출을 실행하지 않습니다. 가격·잔액·레벨·소유·장착은 서버 메모리만 신뢰합니다.
- 이탈/종료 저장은 최대 25초를 기다립니다. 플랫폼이 더 빨리 서버를 중단하거나 요청이 오래 걸리면 저장 확인 실패를 로그로 남기며 임대는 만료됩니다. 새 서버가 임대를 빼앗아 오래된 지갑을 덮는 경로는 차단하지만, 실제 Roblox 장애/동시 서버 검증은 남았습니다.
- 최초 기획의 flat v1/기본 스킨만 명시적으로 이행합니다. 미지원 스키마/손상 기록은 자동 초기화하거나 수리하지 않습니다. Level은 XP에서 다시 계산합니다.
- 모자/배지는 생성 파트이며 여러 아바타 크기/R6/R15·기존 모자와의 겹침, 리스폰 재착용, 민트 스쿠터 실제 외형은 Studio에서 확인해야 합니다.
- 사운드 음소거 설정은 아직 세션 전용입니다. 현재 영구 보존 범위는 Coins/XP/누적 배달/보유/장착입니다. 튜토리얼 완료 플래그/접근성 설정 저장은 P6에서 확장합니다.
- 확인할 항목과 기대값은 `docs/USER_VERIFICATION.md`에 따로 정리했습니다.
