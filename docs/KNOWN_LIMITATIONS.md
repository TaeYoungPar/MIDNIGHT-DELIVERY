# 알려진 제한과 설계 조정

## 출시 차단 / 미구현

- Roblox Studio가 이 Linux 실행 환경에 없어 Play/렌더링/물리/실제 복제는 미검증. 출시 가능한 수준으로 선언하지 않습니다.
- P1은 1건 배달입니다. 파란 집의 고객은 일반 배달 `NormalP1`; 유령 3회 노크 규칙을 구현했다고 오해하지 않도록 분리했습니다. P2에서 고객별 상태/규칙을 추가합니다.
- Coins와 XP는 메모리/Player Attribute 전용입니다. 퇴장/서버 종료 시 사라지며 현재 화면에 세션 전용임을 표시합니다. 저장/레벨/상점은 P5입니다.
- 스쿠터·커스텀 캐릭터/괴물·추격·구조·달리기·설정 UI·음향은 미구현. 기본 Roblox 캐릭터와 조작을 사용합니다. 주차 구획은 장식이며 차량이 아닙니다.
- 서버 정원 4명은 경험 설정에서 직접 지정해야 합니다. 코드는 최대 네 명만 라운드 참가자로 확정합니다.

## P0/P1을 위한 조정

- 전체 지면은 650 studs를 유지하되 첫 배달집은 본부에서 도보로 도달하기 쉽게 배치했습니다. 스쿠터가 없는 P1에서 원본 좌표의 긴 이동을 강요하지 않기 위함입니다. Config.Map에서 조정 가능하고 차량 도입 후 25~60초 동선을 실측해야 합니다.
- 후속 주택은 구역 외형만 생성하며 목적지/프롬프트는 활성화하지 않았습니다. 배달이 되는 것처럼 표시하지 않습니다.
- 목표는 화면 좌표를 사용한 화살표로 안내합니다. 작은 화면에서 다른 HUD와의 겹침/카메라 뒤쪽 목표는 Studio QA가 필요합니다.
- 현재 보안의 이동 속도 검사는 급격한 위치 변화에 3초 배달 지연을 주는 초기 휴리스틱입니다. 장시간 위치 위조/느린 텔레포트 방어가 완성된 것은 아닙니다. P4 이동 모드/차량 권위와 함께 강화하고 지연/낙하 오탐도 검사해야 합니다.
- ProximityPrompt의 HoldDuration은 UX용입니다. 보상은 서버의 활성 주문/시간/참가/생존/거리/멱등성으로 보호하며 클라이언트의 홀드 시간 자체를 신뢰하지 않습니다.
- 새 월드 교체는 생성 폴더에 한정합니다. 기존 Place의 기본 Baseplate/Spawn이나 별도 Lighting 효과는 삭제하지 않습니다. **빌드 파일 열기** 또는 빈 Place 사용이 권장됩니다.

## 이후 해결할 항목

맵 외곽 경계/낙하 복구, 도로 지름길/2개 도주 경로, 고유 몬스터·차량 모델, 모바일 실기기 30FPS, DataStore 경쟁 세션/실패 복구, 전체 QA_CHECKLIST, 출시 설정/연령 등급. 실제 유료 판매는 MVP 이후이며 임의 상품 ID는 없습니다.

## 빌드 파일 전달

실행 ZIP은 GitHub의 `downloads/MidnightDelivery-Studio.zip`에서 받습니다. 저장소가 비공개라면 접근 가능한 GitHub 계정으로 로그인해야 합니다. ZIP 배포는 Roblox 게임 게시나 Studio 실행 검증을 의미하지 않습니다.
