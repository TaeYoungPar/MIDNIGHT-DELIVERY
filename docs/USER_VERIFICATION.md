## 최신 파일 우선 재검증

- [ ] 노크3회 후 돌아보면 멀리서 괴물이 보이고 이름표/윤곽으로 구분되며 1초 뒤 추격합니다. 집/벽 안이나 몸에 겹쳐 생성되지 않아야 합니다.
- [ ] 대기/가방 준비 중 주황 출발선을 도보·차량·점프로 넘을 수 없고, 목적지가 미리 노출되지 않습니다. 출발 때 선이 열립니다.
- [ ] 탑승 중 문 프롬프트가 숨겨지고, 노크·배달·진정 보상이 발생하지 않습니다. 하차 후 다시 가능해야 합니다.
- [ ] 세 주문 완료 후 결과15초→대기20초→준비10초→다음 판인지 확인합니다. 멈추면 화면 상단 단계/카운트다운과 Output의 빨간 오류, `Round N:` 로그 마지막 행을 기록합니다. 현재 실제 멈춤 원인은 미확정입니다.

- [ ] 유령집에서 정상 노크 3회에 각각 타격음과 노크 횟수를 확인합니다. 연타/먼 거리/관전자는 노크를 발생시키지 않아야 합니다. 메뉴의 소리 끄기도 확인합니다.
- [ ] 세 번째 노크 후 문을 향해 4초 유지 → 보상 → 다음 목적지(첫 판: 거인집) 안내/HUD가 바뀝니다.
- [ ] 주행 시 직진·최고속도·좌우 번갈아 조향·도로 경계·제동·후진에서 남은 떨림을 확인합니다. R6/R15·2/4인·모바일·고지연에서도 검사합니다.

아래는 **아직 실제 Roblox Studio/기기에서 테스트하지 못한 항목**입니다. 전부 미확인 상태로 남겨 두었습니다. 자동 로직/대역 검사 PASS와 구분합니다.

## 이번 수정 우선 확인: 스쿠터 3분 점검

최신 파일에는 **떨림·엔진음 수정**도 포함됩니다. 아래 확인은 아직 미검증입니다.

- [ ] 정차→가속→최고속도→제동·후진을 반복하고 도로 중앙선/교차로/도로-잔디 경계를 통과합니다. 카메라 주시점·차체·탑승자가 번갈아 튀지 않아야 합니다. 벽 옆 회전 후 카메라가 갑자기 멀어지지 않아야 합니다.
- [ ] 정차한 채 탑승하면 낮은 엔진 공회전, 가속하면 부드럽게 높아지는 엔진음이 들립니다. 빠른 발소리 반복이 없어야 합니다. 하차하면 엔진이 멈추고 도보 발소리가 돌아와야 합니다. 소리 꺼짐도 확인합니다.
- [ ] 엔진이 무음이면 Output의 `Audio unavailable`/에셋 접근 오류와 `6002661882`를 확인합니다. 외부 오디오의 경험별 재생 권한은 이 클라우드에서 확인하지 못했습니다. `AUDIO_SOURCES.md`를 참고합니다.
- [ ] 2인·4인, R6/R15, 모바일, 네트워크 지연 환경에서 동일하게 검사하고, 하차/사망/리스폰/복구 후 회전과 걷기가 정상인지 확인합니다.

이전 파일에서 보고된 시점/소유 표시/하차 문제를 수정한 파일로 다시 검사합니다. 아래는 아직 재검증 전입니다.

- [ ] 본부 앞 민트빛 테두리와 **‘내 스쿠터’** 이름표가 있는 차량을 쉽게 찾을 수 있습니다. 다른 차량은 타라는 프롬프트가 표시되지 않습니다.
- [ ] E/터치로 탑승하면 카메라가 차량의 **뒤·위**에서 앞길을 보여줍니다. 직진/좌회전/우회전/후진 중 뒤집힘·급격한 줌·심한 떨림이 없는지 확인합니다.
- [ ] 정지 상태에서 **X**, 다시 탑승 후 **Space**, 다시 탑승 후 오른쪽 **하차 버튼**을 각각 시험합니다. 캐릭터가 옆 공간으로 내려오고 WASD/점프가 작동하며 기본 카메라가 돌아와야 합니다. 재탑승은 1초 뒤부터 가능합니다.
- [ ] 주행 중 하차, 벽 옆 하차, 내린 직후 버튼 연타, 탑승 중 차량 복구를 확인합니다. 벽 속/좌석에 고정되거나 이미 내린 캐릭터가 반복 이동하면 오류입니다. 주변이 모두 막힌 때의 본부 복귀는 의도한 동작입니다.
- [ ] 가능하면 모바일에서 하차 버튼이 기본 점프/방향 버튼과 겹치지 않고 눌리는지, 2인에서 각자 자기 표시만 보이고 상대 차량을 탈 수 없는지 확인합니다.

## 1. 준비: 저장/상점을 시험할 때만 필요

- [ ] GitHub에서 최신 `MidnightDelivery.rbxlx`를 받아 Studio의 파일에서 열기로 엽니다. 이전 파일을 다시 열면 새 변경이 반영되지 않습니다.
- [ ] **별도의 비공개 테스트 경험**으로 Roblox에 게시합니다. 공개 출시할 필요는 없습니다.
- [ ] 테스트 경험의 Experience Settings/게임 설정 → Security/보안 → **Enable Studio Access to API Services**를 켭니다. 실제 서비스 중인 경험에서 시험하지 않습니다.
- [ ] 경험 최대 인원은 **4명**으로 설정합니다.
- [ ] Play 후 HUD에 `영구 저장 연결됨`이 나타나는지 확인합니다. `프로필 로딩 중`에는 참가 대기, `세션 전용`에는 게임만 실행되며 상점이 잠깁니다. 게시/API 설정 또는 잠금/저장 연결을 확인하세요.

**중요:** Studio와 Roblox 앱은 저장 공간을 의도적으로 분리했습니다. Studio 플레이로 얻은 재화가 Roblox 앱에 안 보이는 것은 정상입니다. 같은 방식으로 나갔다 들어와야 복원을 비교할 수 있습니다.

## 2. 첫 실행·설정·안내와 한 판

- [ ] 상단 메뉴에서 소리/차량 복구/상점/화면 설정/게임 방법을 열 수 있습니다. 낮은 화면에서는 스크롤로 모든 항목에 접근합니다.
- [ ] 첫 안내 3단계, 닫기, 다시 보기가 작동합니다. 중도 합류자는 대기 안내를 읽을 수 있고 라운드가 멈추지 않습니다.
- [ ] HUD 글자 크게, 카드 자동/접기/펼치기, 알림 애니메이션 줄이기를 바꾸고 메뉴·조작·핵심 안내가 가려지지 않는지 확인합니다.
- [ ] 소리 끄기를 저장한 뒤 재접속 시 초반에 원치 않는 소리가 나지 않습니다. 설정과 안내 여부는 저장 연결에서 복원됩니다. 세션 전용에서는 재접속 시 초기화가 정상입니다.
- [ ] 이전 v1 지갑이 있으면 최신 P6 파일에서 재화/인벤토리를 유지하며 v2로 이행되는지 확인합니다. 구 P5 파일에서는 새 형식을 세션 전용으로 처리하므로 최신 파일로 시험합니다.



- [ ] 캐릭터/첫 카메라가 본부에서 도로를 향합니다. 자유롭게 카메라를 돌릴 수 있습니다.
- [ ] 20초 로비 → 10초 준비 → 주문 3건 → 결과 15초 → 다음 판으로 이어집니다.
- [ ] 파란 집의 양면 표지판과 3D 화살표가 실제 파란 지붕집을 안내합니다.
- [ ] 유령: 3회 노크 후 캐릭터가 문을 향한 채 4초 유지. 카메라만 돌릴 때 잘못 판정하지 않습니다.
- [ ] 거인: 90초 안에 정상 배달. 늦으면 3초 진정으로 56 Coins. 가짜 집은 우편함 표식/색·현관등 단서가 맞아야 합니다.
- [ ] 주문 실패/120초 경과에도 다음 주문으로 넘어갑니다. 다음 판 시작 고객/정답 단서가 바뀝니다.

## 3. 스쿠터·모바일·소리

- [ ] 본부 앞 ‘내 스쿠터’ 표시/민트빛 테두리 차량만 E/터치로 탑승합니다. 다른 사람 차량을 운전/복구할 수 없습니다.
- [ ] PC WASD/방향키, 모바일 ↑↓←→ 버튼으로 전진·후진·조향. **모델과 캐릭터가 함께 움직이는지** 확인합니다.
- [ ] X/스페이스/오른쪽 하차 버튼으로 정상 하차. 차량 복구는 본부 주차 칸으로 돌아오고 15초 연타가 제한됩니다.
- [ ] 벽 정면/옆면/회전 중 충돌, 계단·도로 가장자리, 두 차량 근접에서 관통/고착/카메라 오류가 없는지 확인합니다.
- [ ] Shift/달리기 버튼은 약 5초 지속, 소진 후 약 5초 충전. 기절/탑승 중에는 달리지 않습니다.
- [ ] 지도 밖/낙하 시 본부로 복귀하고 다시 움직일 수 있습니다.
- [ ] 주문·성공·추격·기절/복귀 소리, 바람·주행 루프가 실제로 들립니다. 기본 내장 음색을 사용한 임시 사운드입니다.
- [ ] 소리 켜기/끄기가 동작하고, 음소거해도 자막으로 사건을 알 수 있습니다.
- [ ] 모바일에서 조이스틱/점프/문 프롬프트/달리기/운전/상점 버튼이 겹치지 않고 누를 수 있습니다.

## 4. 괴물·기절·구조

- [ ] 유령 규칙 위반/거인 시간 초과/가짜 집 첫 오답 때 해당 괴물 1마리가 추격합니다. 각각 10/12/8초 후 제거됩니다.
- [ ] 벽 뒤에서 단순 거리만으로 잡히지 않습니다. 막히더라도 NPC가 끝없이 남거나 순간이동하지 않습니다.
- [ ] 잡히면 체력은 유지하고 12초 기절합니다. 혼자 기다리면 도로로 복귀하고 4초 보호됩니다.
- [ ] 2명 이상에서 팀원이 가까이서 3초 눌러 구조합니다. 놓거나 멀어지면 취소, 자신/대기자/먼 거리/벽 뒤 구조는 거부됩니다.
- [ ] 추격 중 이탈/리스폰, 탑승 중 기절, 기절 중 리스폰, 라운드 종료 후 캐릭터 고정/프롬프트/NPC 잔류가 없습니다.

## 5. 저장·레벨·상점 — 같은 테스트 경험/접속 방식으로 검사

- [ ] 새 프로필에서 세 건을 모두 정상 배달하면 첫 판 **360 Coins / 60 XP / Lv.1**, 두 판 누적 **720 Coins / 120 XP / Lv.2**입니다. 실패/식은 음식이 있으면 보상이 달라집니다.
- [ ] 꾸미기 상점에서 모자 120 / 민트 스쿠터 180 / 유령 배지 240 Coins 구매. 세 가지를 모두 사면 위 조건에서 잔액은 **180 Coins**입니다.
- [ ] 구매만 하면 자동 장착되지 않습니다. 장착/해제를 눌러 모자·배지와 스쿠터 색상이 실제로 바뀌는지 확인합니다. 성능은 바뀌지 않습니다.
- [ ] 이미 보유한 상품을 연타해도 추가 차감되지 않습니다. 잔액/레벨 부족 상품은 살 수 없습니다. 장착/해제에는 Coins가 들지 않습니다.
- [ ] HUD의 `변경 저장 대기`가 사라질 때까지 기다리고 Stop 후 같은 Studio 경험에서 다시 Play. Coins/XP/레벨/보유/장착이 유지되어야 합니다.
- [ ] 빠르게 종료한 뒤 재접속도 검사합니다. 저장/종료 오류는 Output 전체를 기록합니다. 갑작스런 종료/Roblox 장애 시 마지막 저장 이후 진행이 유실될 수 있으므로 정상 저장 복원과 구분합니다.
- [ ] 별도로 Roblox 앱에서 비공개 테스트 경험에 들어가 배달·구매 후 나갔다 다시 들어옵니다. 이 앱용 데이터도 유지되어야 합니다. Studio 재화와 다르게 시작하는 것은 정상입니다.
- [ ] API 접근을 끈 **테스트 환경**에서 세션 전용/상점 잠금 안내가 나타나는지 확인합니다. 기존 영구 데이터가 기본값으로 덮어써지면 안 됩니다. 다시 켜고 재접속해 원래 데이터를 확인합니다.

## 6. 2·4인 및 출시 전 확인

출시 가능 판정은 별도 `docs/RELEASE_READINESS.md`의 미검증 항목을 실제로 통과한 뒤 내립니다.

- [ ] 같은 주문/시간이 보이고 동시 배달에도 각 참가자 한 번만 보상됩니다. 중도 합류자는 다음 판부터 참가/보상됩니다.
- [ ] 4대 동시 운전, 높은 네트워크 지연, 모바일 실기기 FPS와 UI를 확인합니다.
- [ ] 20판 반복 시 GUI/차량/괴물/연결이 계속 늘지 않는지 확인합니다.
- [ ] 실제 출시 전 전체 `QA_CHECKLIST.md`를 별도로 수행합니다. 고급 데이터 충돌/장애·보안 시험은 개발 QA에서 추가 검증해야 합니다.

## 문제를 알려주실 때

다운로드한 빌드 버전, Studio인지 Roblox 앱인지, 인원/기기, 하던 행동과 기대/실제 결과, **Output의 빨간 오류 원문**을 함께 보내주세요. 화면/영상이 있으면 방향·차량·버튼 겹침 진단에 도움이 됩니다. 비밀 키나 계정 비밀번호는 필요하지 않습니다.
